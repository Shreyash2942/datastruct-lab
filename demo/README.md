# Demonstration recording

[Download the current walkthrough](datastruct-lab-demo.mp4).

The author supplied this approximately 12-minute, 8-second screen recording.
The repository copy uses H.264 video and AAC audio at the original 1920 × 1032
resolution. Video was recompressed for GitHub storage; the audio stream was
copied without re-encoding. The original recording is preserved locally outside
the repository in the parent recording-originals folder.

The current MP4 replaces the earlier 4:51 computer-narrated demonstration.
[transcript.md](transcript.md) and [captions.vtt](captions.vtt) are historical
materials for that earlier video. They are not synchronized with the current
recording. The previous video's downloaded benchmark ZIP is no longer included.

For reproducible project measurements, see the
[performance report](../reports/performance_report.md) and saved data/ files.
Live benchmark timings may differ from these saved measurements.
